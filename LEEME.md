# House Party Eventos

## Cómo subir fotos a la galería desde el móvil
1. Abrí tu repositorio en github.com (navegador del móvil) o en la app de GitHub.
2. Entrá a la carpeta `galeria`.
3. Tocá **Add file → Upload files**, elegí las fotos de tu galería y tocá **Commit changes**.
4. Esperá 1–2 minutos: la web se actualiza sola.

Para quitar una foto: abrila dentro de `galeria`, tocá los tres puntos (⋯) → **Delete file**.

Tip: usá fotos en JPG/PNG/WebP. Si podés, subilas de menos de 2 MB para que la web cargue rápido.
